ARCHITECTURAL OPTIONS
======================
The diagram legibility defect requires choosing one of four architectural paths:

Option A: Reduce ViewBox width to 390px
- Tradeoff: diagrams become 71% smaller on desktop (768px+)
- Requires re-measuring and possibly re-authoring all eight

Option B: Author at smaller font (7px instead of 10px)
- Tradeoff: desktop rendering too small by default
- Requires font-size rework on all diagrams

Option C: Responsive diagram component
- Detect viewport width, serve different ViewBox or font-size per screen
- Tradeoff: component complexity, multiple authoring versions, multi-breakpoint testing
- This is the long-term solution but outside packet 36's scope

Option D: Defer diagrams
- Reduce `diagrams` to [] and mark section diagram-pending
- Tradeoff: loses profit waterfall, working capital cycle, labelled statement
- Requires marking structure-06, specGap-04, topFix-03 as still-open for later packet
